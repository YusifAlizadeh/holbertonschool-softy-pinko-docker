# 🐳 Holbertonschool Softy Pinko Docker

This project focuses on containerizing the **Softy Pinko application** using Docker.
The objective is to understand how to package an application and its environment into a container for easier deployment and consistency across different systems.

---

## 📌 Project Overview

The **Softy Pinko Docker project** demonstrates how Docker can be used to run an application in an isolated environment.

Using containers helps ensure that the application works the same way on every machine by packaging:

* the application code
* dependencies
* runtime environment
* configuration

---

## ⚙️ Technologies Used

* **Docker**
* **Dockerfile**
* **Linux**
* **Basic container networking**

---

## 🧩 Project Structure

* `Dockerfile` – Defines how the Docker image is built
* `docker-compose.yml` (if used) – Helps manage and run containers
* Application files – The Softy Pinko web application

---

## 🚀 Learning Objectives

Through this project I learned how to:

* Build Docker images
* Run containers
* Understand containerization concepts
* Manage application environments using Docker
* Simplify deployment using containers

---

## ▶️ Running the Project

Example workflow:

1. Build the Docker image
2. Run the container
3. Access the application from the browser

Docker makes it easy to deploy the application without installing all dependencies manually.
